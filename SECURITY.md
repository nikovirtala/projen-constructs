# Security Policy

## Supported versions

Security fixes are provided for the latest published release line of `@nikovirtala/projen-constructs`. Older versions are not maintained; please upgrade to the most recent release to receive fixes.

| Version | Supported |
| --- | --- |
| Latest release line | ✅ |
| Older releases | ❌ |

## Reporting a vulnerability

Please report security vulnerabilities privately rather than opening a public issue.

- **Preferred:** open a [private security advisory](https://github.com/nikovirtala/projen-constructs/security/advisories/new) on GitHub.
- **Alternatively:** email the maintainer at [niko.virtala@hey.com](mailto:niko.virtala@hey.com).

Please include enough detail to reproduce the issue (affected version, steps, and impact).

## Response expectations

- You can expect an acknowledgement of your report within a few business days.
- Once triaged, the maintainer will work on a fix and coordinate a disclosure timeline with you.
- You will be credited for the report unless you prefer to remain anonymous.
